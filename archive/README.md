# Archive — legacy Istanbul map

This folder preserves superseded code that is intentionally **not** built or
imported by the app. Kept for reference only.

## `IstanbulUniversityMapPage.codex-3d-original.jsx`

The **original Codex-generated 3D map** (the stylised low-poly Three.js scene —
green hills, toy trees, simple volumes). Captured from the tip of the
`codex/istanbul-3d-university-map` branch (`88207bd "Upgrade Istanbul map
cinematic geography"`) before that branch was deleted. This is the "old map"
generated by Codex that you asked to keep for reference.

## `IstanbulUniversityMapPage.legacy-pre-mapbox.jsx`

A later snapshot of the map **just before the Mapbox GL migration** (still the
low-poly scene + the old MapLibre raster setup). Captured from git commit
`56097b8` (immediately before `c5fbb2b "Istanbul map: migrate engine MapLibre ->
Mapbox GL JS v3"`).

### Note
The live map (`src/components/pages/IstanbulUniversityMapPage.jsx`) is now the
cinematic **Mapbox** map with typed 3D building archetypes. The same low-poly
scene still ships **inside** the live component as the automatic fallback used
when WebGL or the Mapbox token is unavailable — so the old look is never lost,
it just no longer shows when the real map can render.
